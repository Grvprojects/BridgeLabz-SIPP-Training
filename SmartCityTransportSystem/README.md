# Smart City Transport & Service Management System (Java 8)

This sample project demonstrates Java 8 features requested:
- Lambda expressions, method references, functional interfaces
- Default & static methods in interfaces
- Streams, Collectors (groupingBy, partitioningBy, summarizingDouble)
- forEach(), method references, and marker interfaces
- Easy extensibility for new services

Run the sample by compiling all `.java` files and running `SmartCityApp`:
```
javac *.java
java SmartCityApp
```

The app simulates booking, dashboard updates, revenue reporting, and emergency prioritization.
